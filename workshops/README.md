Hands-on exercises for Copilot onboarding sessions. Each workshop is self-contained and takes 45–60 minutes.

## Running a workshop

- Participants need Copilot installed and working before the session starts.
- Each exercise has a goal, steps, and a debrief question. Run exercises, then discuss as a group.
- Adapt examples to the team's primary language — the concepts transfer across stacks.
