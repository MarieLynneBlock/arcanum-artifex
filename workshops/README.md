# Workshops

Hands-on exercises for Copilot onboarding sessions. Each workshop is self-contained and takes 45–60 minutes.

## Sequence

| # | Workshop | Audience | Duration |
| --- | --- | --- | --- |
| 01 | [Completions](01-completions.md) | All developers | 45 min |
| 02 | [Chat & Participants](02-chat-and-participants.md) | All developers | 60 min |
| 03 | [Prompt Engineering](03-prompt-engineering.md) | Intermediate+ | 60 min |

## Running a workshop

- Participants need Copilot installed and working before the session starts. Use [getting-started.md](../guides/getting-started.md).
- Each exercise has a goal, steps, and a debrief question. Run exercises, then discuss as a group.
- Adapt examples to the team's primary language — the concepts transfer across stacks.
