# Scientific Agents

Custom `.agent.md` definitions for research, literature review, and data pipelines.

## Agents

| Agent | Description |
| --- | --- |
| [Scientific Paper Research](research/scientific-paper-research.agent.md) | Research agent that searches scientific papers and retrieves structured experimental data from full-text studies using the BGPT MCP server. |

## Deploy

Copy an `.agent.md` file into `.github/agents/` (project) or a personal agents directory (`~/.claude/agents/`, `~/.copilot/agents/`, `~/.agents/`).
