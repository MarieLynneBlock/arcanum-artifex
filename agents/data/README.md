# Data Agents

Custom `.agent.md` definitions for data storytelling, analysis critique, and evidence quality.

## Agents

| Agent | Description |
| --- | --- |
| [Data Storytelling Critic](data-storytelling-critic.agent.md) | Critiques data stories for evidential integrity, narrative clarity, visual effectiveness, accessibility, and decision usefulness. |

## Deploy

Copy an `.agent.md` file into `.github/agents/` (project) or a personal agents directory (`~/.claude/agents/`, `~/.copilot/agents/`, `~/.agents/`).
