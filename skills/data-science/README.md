# Data Science Skills

This category contains skills for analytics, experimentation, model evaluation, and notebook-centric workflows.

## Featured Skills

| [Dash](dash/SKILL.md) | Building or debugging Plotly Dash apps: layout, callback wiring (State, chained, pattern-matching, duplicate outputs), sharing data between callbacks without global state, multi-page apps with Dash Pages, and choosing clientside/background callbacks for performance. Includes callback and architecture references plus a tested runnable example with unit tests. |
| [MLflow](mlflow/SKILL.md) | Tracking reproducible experiments, evaluating and selecting models, packaging custom models, working with GenAI/agents, or preparing governed inference across Python/R and local, OpenShift or AWS environments. Includes reference examples, a metric comparator and reusable evidence templates. |
| [Pandas Data Wrangling](pandas-data-wrangling/SKILL.md) | Cleaning, typing, deduplicating, joining, grouping, reshaping and time-aligning tables with explicit contracts and reconciliation checks. Includes focused references and executable synthetic examples; wrangling only. |
| [Survival Analysis](survival-analysis/SKILL.md) | Designing, implementing, diagnosing, evaluating or reviewing time-to-event analyses, from churn and censoring to competing risks and dynamic prediction, including large-cohort runtime and sampling designs. Includes statistical references, a glossary and troubleshooting tables, planning/reporting templates, a tested synthetic Python workflow and a secondary R example. |
