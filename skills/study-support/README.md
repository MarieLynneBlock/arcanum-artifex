# Study Support Skills

This category contains skills for learning aids, flashcards, and concept-explanation frameworks.

## Skills

| Skill | Description |
| --- | --- |
| [code-to-coach](code-to-coach/SKILL.md) | Deconstruct code into bite-sized, logical chunks from a coaching perspective. Remove abstraction, explain the "why" behind each concept, identify best practices, code smells, and cognitive load issues. |
| [exam-ready](exam-ready/SKILL.md) | For each syllabus topic, extract from the provided material: - What it is (1 line definition — exam-ready) - 3–5 key points an examiner expects - Important keywords to use in the answer (bold them) - Any important diagram or figure — describe what it shows in 2 lines - 1–2 sentences the student can directly write in their exam answer (or MCQ trick if exam type is MCQ) - 1 examiner-style practice question to test recall |

## Add a skill here

1. Copy the template from `../../templates/skills/skill_blank/`.
2. Use a scope-first, kebab-case name.
3. Define expected outputs and evidence standards.
