# Python Skills

Skills for Python development workflows, idioms, and ecosystem tooling.

## Skills

| Skill | Description |
| --- | --- |
| [create-pytests](create-pytests/SKILL.md) | Generate pytest test files targeting 80% line coverage for a Python project or targeted scope, with pyproject.toml setup (hatchling + importlib mode) and a Coverage Gap Report. |

## Add a skill here

1. Copy the template from `../../../templates/skills/skill_blank/`.
2. Place the folder under `skills/development/python/<skill-name>/`.
3. Name by library, pattern, or workflow (e.g. `async-patterns`, `type-annotations`, `packaging`).
4. Add a row to the table above and update [`../README.md`](../README.md) if needed.
