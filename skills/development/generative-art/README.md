## Add a skill here

1. Copy the template from `../../../templates/skills/skill_blank/`.
2. Place the folder under `skills/development/generative-art/<skill-name>/`.
3. Name by pattern, medium, or workflow (e.g. `noise-fields`, `particle-systems`, `procedural-typography`, `interactive-installations`).
4. Add a row to the table above and update [`../README.md`](../README.md) if needed.
