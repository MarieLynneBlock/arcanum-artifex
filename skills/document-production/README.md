# Document Production Skills

This category contains skills focused on producing publication-ready and presentation-ready documents.

## Included skills

- `docx`
- `latex-posters`
- `markitdown`
- `pdf`
- `pptx`
- `pptx-posters`
- `scientific-slides`
- `xlsx`

## Add a skill here

1. Copy the template from `templates/skills/skill_blank/`.
2. Name the folder with a clear document workflow label.
3. Keep examples and references focused on verified workflows.
